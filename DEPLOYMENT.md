# Deployment

This fork uses Cloudflare Workers Builds for production deployment from `main`.

## Update

1. Open this repository and choose `Sync fork`, then `Update branch`.
2. Wait for the Cloudflare build and deployment to succeed.
3. Check the dashboard version, node status, and history charts.

Theme updates and Agent updates are separate from Worker updates.
Do not commit credentials or change the existing database binding during an update.
